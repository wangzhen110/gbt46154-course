### 跨设备无缝同步

进度保存在浏览器 localStorage（同源隔离），**不会自动跨设备**。换设备时请：

1. 旧设备：进入任意视图 → 侧栏「导出 / 导入进度」或移动端「进度同步」→ 点「导出进度」得到一个 JSON 文件。
2. 通过任意方式（微信传文件 / 网盘 / 邮件）把它发到新设备。
3. 新设备打开在线版或本地单文件版 → 同样入口点「导入进度」→ 选择该 JSON 文件 → 进度合并（已答记录叠加，错题保留）。

## 怎么用

1. **讲解模式**（左侧导航切换）：每章 3~7 屏图文讲解，可「自动播放」逐屏推进；点「语音讲解」后由浏览器朗读当前屏内容（Chrome / Edge 支持中文），边听边学，等同于视频课程体验。
2. **答题模式**：选完选项立即判定，**答对答错都会显示解析与出处**。支持按章节 / 题型 / 范围（未作答、错题、已答对）筛选，可随机打乱，支持 1~6 数字键选选项、回车下一题。
3. **统计模式**：总正确率、各章掌握度、错题清单（可点击直接跳回该题）。

答题记录保存在浏览器本地（localStorage），关闭不丢失；「清空学习记录」可重置。

## 出处说明

每道题的「出处」字段精确到**条款号或附录条目**，例如：

- `5.2.1.3 额定载重量`
- `表2 注2`
- `B.2.11.1.4`
- `附录A 表A.1（续）`
- `5.10.3.13；第1章；5.7.2.2`（跨条款对照题）

解析部分不只给出答案，而是说明**为什么**：写明判定依据、易混淆点对照（如 0.40 / 0.63 / 0.70 m/s 三组速度，125% / 130% / 150% / 300% 等载荷百分比），以及与其他条款的关联。

## 几点说明

- 题库严格依据 PDF 原文编写，未引入外部推测内容；标准中数字被拆行排版的部分（如「3. 1. 1」）已还原为「3.1.1」。
- 讲解幻灯片是对标准条款的**提炼**，不能替代标准原文，涉及设计、检验结论时仍须以标准正文为准。
- 如需 MP4 视频文件（而非当前的语音讲解幻灯片），可以另行生成，但需说明：AI 生成的视频画面难以准确表达本标准的技术细节，建议用于导学/概览，细节学习仍以本题库为主。
